One word for my ex: **Unsubscribe**.

The ex, reframed as a newsletter nobody asked for — opted out of, cancelled, gone from the inbox for good. Running `main.py` writes exactly that one word to `$OUTPUT_DIR/entry.txt` (default `/output`).

## Run

```sh
python3 main.py
```

Set `OUTPUT_DIR` to choose where `entry.txt` is written.
